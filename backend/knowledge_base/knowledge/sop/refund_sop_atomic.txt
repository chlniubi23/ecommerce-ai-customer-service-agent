
# 原子知识卡：客服处理退款的标准流程（内部SOP）

## 元数据
- 知识分类：sop
- 文档类型：atomic_knowledge
- 检索关键词：客服退款流程、退款标准流程、退款SOP步骤、客服处理退款、退款处理规范、售后SOP
- 可回答问题：
  - 客服处理退款的标准流程是什么？
  - 退款SOP的步骤有哪些？
  - 客服处理退款有哪些规范要求？

## 标准答案
客服处理退款按以下标准流程执行：
1. 识别诉求：确认用户要退的是哪个订单、什么原因（质量问题/不想要了/未收到货等）。
2. 核对订单：查询订单状态、支付记录、商品与物流信息。
3. 判定规则：对照七天无理由条件、退款拒绝场景和售后时限判断是否可退。
4. 引导申请：符合规则的引导用户在订单页提交退款申请；不符合的说明原因与依据。
5. 审核跟进：退款提交后进入售后审核，审核通过按退款规则原路退回。
6. 记录归档：处理结论、依据和承诺必须记录在工单中。

## 适用条件
- 面向客服/知识 agent 的退款处理规范问答。
- 用户咨询"你们怎么处理退款""退款流程是什么"类问题。

## 不适用场景
- 用户具体订单的退款进度查询：以售后系统记录为准。
- 财务与对账口径的退款计算：不属于客服SOP范围。

## Knowledge Agent 回答要求
- 按步骤概述流程，突出"申请-审核-原路退回"三个关键环节。
- 说明到账时间时区分平台审核时效与支付渠道入账时效。
- 不得替用户预判审核结果。
